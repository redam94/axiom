Benchmarks · 12 published values

Numbers other people published

Every other test in this repository checks axiom against a world axiom made up. That is the right way to ask whether an estimator recovers a truth, and it is circular in one respect: the data-generating process and the likelihood are the same code.

These close the loop from outside — four datasets collected by other people, and 12 results computed by other software before this library existed. Largest relative disagreement anywhere: 3.3e-04.

The four

What is checked, and against whom

Each one covers a different pillar and a different reference implementation. Two are committed to the repository and run anywhere; two carry licences a proprietary repository cannot satisfy by redistributing them, and are fetched on request.

What this found

An 0.001 disagreement worth chasing

The first BCG run disagreed with metafor on I² by 0.001 — small enough to look like a rounding error, and the sort of thing a tolerance quietly absorbs.

Q-based (Q − df) / Q — the original Higgins & Thompson definition, and what axiom.meta.heterogeneity returns 0.9212
model-based τ² / (τ² + s²) with s² the typical within-study variance — what metafor's rma() prints 0.9222
verdict Neither is wrong. They answer slightly different questions, and reconstructing metafor's definition from axiom's outputs reproduces its published value exactly. both pinned

The wrong fix

Widening the tolerance until the table went green. It would have passed, it would have looked identical in CI, and it would have thrown away the only interesting thing the benchmark had to say. Both definitions are now asserted, so if either moves it is a deliberate change rather than a silent one.

This is what benchmarks against other people's software are for. Self-consistency tests cannot find a definitional difference, because both sides of the comparison share the definition.

A word about that I^2, because the first run of this file looked like a bug.
    axiom's heterogeneity() returns the Q-BASED I^2, (Q - df) / Q = 0.9212.
    metafor's rma() prints the MODEL-BASED one, tau^2 / (tau^2 + s^2) = 0.9222,
    where s^2 is Higgins & Thompson's typical within-study variance.

    They differ by 0.0010 here -- small enough to look like a rounding
    error and large enough to be worth chasing. Neither is wrong; they answer
    slightly different questions. What would have been wrong is quietly widening
    the tolerance until the table went green.

Reading it
    Every published quantity reproduced. That is the claim worth making: not that
    axiom's formulas are self-consistent -- the unit tests already cover that --
    but that running this library end to end on somebody else's data lands where
    somebody else's software landed.

    The substantive reading is the second half. A pooled risk ratio around 0.49
    looks decisive until you notice I-squared above 90% and a prediction interval
    that reaches almost to 1.0. The average of thirteen trials that disagree this
    much is a number about the thirteen trials, not about the vaccine.

Reading it
    Both certified parameters recovered to about one part in ten thousand, with
    the certified values inside the 95% intervals, and a residual sum of squares
    that sits just above the certified minimum rather than below it.

    That last point is the one worth dwelling on. A fit that reported a LOWER
    residual sum of squares than NIST's certified optimum would not be a better
    fit -- it would be a bug, either in the model being fitted or in the arithmetic
    reporting it. Benchmarks with certified answers catch that class of error,
    which is exactly why NIST publishes them.

    What axiom adds beyond the certified numbers is the last table: NIST reports
    two parameters and their standard deviations, and axiom will also tell you what
    the curve does at a pressure of 1200 and how sure it is.

Licensing

Why half the data is not in the repository

axiom is proprietary. Two of these four datasets carry licences that a proprietary repository cannot satisfy by redistributing them: the Darfur survey ships inside a GPL-3 R package, and the NSW data is CC BY-NC — attributable non-commercial use.

So they are not vendored. A fetch script downloads them into a git-ignored cache on request, prints the licence before doing it, and records the sha256. The tests over them skip when the data is absent, so a fresh clone runs ten passed and four skipped rather than failing.

The two that are committed are safe by a wide margin: the NIST dataset is a work of the US federal government and public domain, and the BCG table is thirteen rows of event counts from a 1994 JAMA paper, reproduced in dozens of textbooks and packages.

shell 
# what is here, and on what terms

# download the restricted ones, licence shown first
python benchmarks/fetch.py
python benchmarks/fetch.py --all

# the assertions, and the case studies
pytest tests/benchmarks -q
python benchmarks/run_all.py
